# Escala 5x2

Página simples que explica a escala 5x2 (5 dias de trabalho e 2 de folga por semana) para trabalhadores e empresários. Não é feita para nenhuma empresa específica.

## Como usar

Abra `index.html` no navegador. Não há build nem dependências.

- **Sou trabalhador / Sou empresário**: troca as perguntas e dicas mostradas. A escolha fica salva no navegador.
- **Lista de tarefas** (modo empresário): salva só no navegador de quem usa.
