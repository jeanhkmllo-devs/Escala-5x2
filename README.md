# Escala 5x2

Página de consulta sobre a escala 5x2 (5 dias trabalhados e 2 de folga por semana), com base na Emenda Constitucional nº 141/2026.

## Como usar

Abra `index.html` no navegador. Não há build nem dependências.

- **Colaborador / Empresário**: chave no topo que muda o conteúdo exibido. A escolha fica salva no navegador.
- **Calculadora de jornada**: informa se a semana passa dos limites de 44 h, 42 h ou 40 h.
- **Gerador de rodízio** (modo Empresário): monta um rascunho mensal com cobertura mínima por dia. Não considera férias, atestados, feriados nem convenção coletiva.
- **Checklist de adequação** (modo Empresário): salvo só no navegador de quem usa.
